## Главные правила работы
- **Не выдумывать правила.** Источник: wiki.bloodontheclocktower.com (страница роли → How to Run, Glossary).
  API: `https://wiki.bloodontheclocktower.com/api.php?action=parse&page=<Роль>&prop=wikitext&format=json`.
  Если на вики нет — сказать «решение рассказчика» или спросить пользователя.
- У пользователя **только базовая коробка**: роли Trouble Brewing, Bad Moon Rising, Sects & Violets (+ их Странники и Сказочники).
  Исключение по просьбе пользователя — сценарий **Catfishing 11.1** (Emily): в нём 4 роли из Carousel, жетонов у пользователя нет —
  Аэронавт (Balloonist), Амнезиак (Amnesiac), Каннибал (Cannibal), Вдова (Widow).
  Ещё по просьбе пользователя (2026-10-08) — сценарии сообщества с botcscripts.com: **Reptiles II: Lizard in the City** (Aero),
  **The Midnight Oasis** (Zets), **Pies Baking** (Ryback), **Uncertain Death** (Matt) — COMMUNITY в pp_build_data.py;
  экспериментальные роли в них помечаются на подготовке, Сказочники сценария (abled) входят в игру при выборе сценария.
- В данных приложения — **все 181 роль** официальных данных (коробка, экспериментальные/Carousel, Странники, Сказочники, Лорики):
  для справочника и своих сценариев (`box: false` — не из коробки). Встроенные сценарии — сценарии пользователя (Everyone Can Be
  Evil, Blind Hunt), коробка, Catfishing и сценарии сообщества.
  У 5 ролей нет официального перевода (Атеист, Ягга-Баббл, Бог Уг, Плуты, Чревовещатель) — название и способность
  в `app/data/guide/*.json` (`name`/`ability`), в карточке помечены как неофициальные.
  Экспериментальные роли в своём сценарии ведутся общими шагами (механику ведёт рассказчик); если раскладку роли приложение
  не знает (`unknownSetup`, `KNOWN_SETUP` в engine.js) — проверка раскладки не блокирует старт; игра без Демона в начале
  (Атеист, Призыватель, Монстрёнок) не заканчивается «смертью Демона» (`S.flags.demonless`).
- Русские названия — из официального `app/data/ru.json` (botc-translations). Совпадают с жетонами пользователя:
  **Цирюльник** (Barber), **Фань Гу** (Fang Gu), Травница (Tea Lady), Кукловод (Mastermind), Растяпа (Klutz).
- Перед публикацией чего-либо наружу (GitHub, пуш, новые загрузки) — спросить пользователя.

## Уточнённые правила (решения пользователя и проверки по вики)
- **Изгнание Странника:** голосуют все игроки (живые и мёртвые), голос призрака НЕ тратится;
  изгнан, если голосов ≥ половины ВСЕХ игроков с округлением вверх (`exileThreshold` в engine.js). Изгнание — не казнь.
- **Странники** не считаются для «двое живых — победа зла», Блудницы (5+), Мэра; в пороге казни считаются (голосуют).
  Сторону Странника назначает рассказчик.
- **Дурманщик (Poppy Grower)** — по вики МОЖЕТ быть пьян/отравлен: если пьян/отравлен в момент смерти — злые не знакомятся;
  если стал пьян/отравлен — злые «внезапно» не узнают друг друга; если Пьяница считает себя Дурманщиком — знакомство как обычно.
  В движке это свойство роли `prevents_evil_meeting` (data), а не проверка по id.
- **Роли Catfishing в движке** (по вики): яд Вдовы действует, пока Вдова жива и трезва; Аэронавт помнит тип показанного
  прошлой ночью (Затворник/Шпион — тип решает рассказчик), +0/+1 Изгой в раскладке; способность Амнезиака — текст от рассказчика,
  днём догадка «Холодно/Тепло/Горячо/В точку»; Каннибал получает роль казнённого и умершего доброго (`gained`), способность
  «только в 1-ю ночь» срабатывает в ночь после казни (шаг `fresh`), съев злого — отравлен, шаг «понарошку» (`fakeCannibal`).
- **Слова для утра** (`app/src/morning.js`): тон мрачно-торжественный (выбор пользователя); имена в именительном падеже и без
  согласования по роду (пол игроков неизвестен); тексты не раскрывают роли и причину смерти.
- **Куртизанка:** по вики умирают оба; по решению пользователя можно выбрать и смерть одного («Только Куртизанка» / «Только выбранный»).
- **Азартный игрок** не узнаёт, угадал ли: подсказка шага помечена `secret` («Только для вас — не показывайте»); не угадал — умирает,
  пьяный/отравленный — нет.
- **Придворный** не узнаёт, сработало ли (подсказка `secret`), как и Азартный игрок.
- **Пукка пьян/отравлен** (вики): новый выбор не отравляет, прежний отравленный не умирает и остаётся отравленным —
  умрёт в ночь, когда Пукка протрезвеет.
- **Выбор ролей способностями** (Азартный игрок, Философ, Церенов, Яга) — только из сценария («на листе персонажей», вики).
- **Искажённая информация:** при пьянстве/яде рекомендация — ложная, при Вортоксе — обязательно ложная; рассказчик может
  выбрать ответ сам (Да/Нет, число, жетон). Шаг помечается зелёной «ядовитой» рамкой с каплями (`spec.dist`, `distortion`).
- **Математик** (вики: «способность должна была сработать, но не сработала» или ложная информация, свой сбой не считается,
  пьянство само по себе — не считается): приложение ведёт учёт `S.flags.abn` (`recordAbn`) с рассвета до рассвета;
  защита Монаха от Демона по вики не определена — не считаем (решение рассказчика).
- **Заклинатель змей** выбрал Демона: обмен ролями и сторонами, остаток ночи перестраивается (`rebuildRest`),
  две плашки «ТЕПЕРЬ ВЫ» (Заклинателю — Демон, прежнему Демону — Заклинатель).
- **Сновидец** (заметка пользователя 2026-10-11): добрая и злая роль — выпадающими списками (не выбрано — рекомендация);
  своя роль Сновидцу не предлагается; доброму игроку ложной — Приспешник из игры (вики: «почти всегда»); пьян/отравлен/Вортокс —
  рекомендация: обе ложные; Странников выбрать нельзя (вики). Гробовщику, Смотрителю, Прачке/Библиотекарю/Сыщику ложной
  рекомендацией тоже не предлагается их собственная роль.
- **Безумие** (заметка пользователя 2026-10-11; вики): **Гарпия** — будят только первого («ОБЛАДАТЕЛЬ ЭТОЙ РОЛИ ВЫБРАЛ ВАС»,
  жетон Гарпии, второй игрок), второму — отметка `second`; днём «умирает первый / второй / оба» (`harpyKill`: смерть, не казнь).
  **Цереновус** и **Уродец** — днём «не помешан — казнить» (`madnessExecute`: это казнь дня, после неё сразу ночь; если сегодня
  уже казнили — нельзя; мёртвого «помешанного» тоже можно). Карточка «Безумие нарушено? — решение рассказчика» на экране дня.
- **Уродец — текст по решению пользователя** (2026-10-11): «Если вы внушаете, что вы Изгой, вас могут казнить.» вместо
  официального «помешаны» — `USER_ABILITY` в `tools/app_build_data.py` (замены текста поверх ru.json). Пользователь называет безумие «внушением».
- **Горизонтальный показ — в два экрана** (заметка пользователя 2026-10-11): сначала карточка на весь экран, по нажатию — роли
  и имена крупно (`UI.show.sub`, `showHasBoth`).
- **Смена ролей — проверка по вики (2026-10-11, просьба пользователя), всё через `changeRole(S, p, role, opts)` в engine.js:**
  новая роль, `gained` и `believes` заново (Пьяница — Горожанин не из игры/блефов, `pickBelieved`; при обмене Цирюльника
  «кем себя считает» и способность Философа/Каннибала едут вместе с ролью); `S.flags.ever`; Философ раньше выбрал эту роль — её
  обладатель пьян; способность «только в 1-ю ночь» новой роли — в ближайшую ночь (`addFresh`, вики-пример Ягa → Злой Близнец);
  эффекты роли, которой больше ни у кого нет, кончаются (`endOrphanEffects`: яд, пьянство, защита, проклятие и т. п.).
  - **Яга**: можно выбрать и роль в игре — «ничего не происходит»; сторона прежняя (жест), ночь перестраивается, создан Демон —
    пометка в шаге Демона «смерти на ваше усмотрение» (`S.night.data.pithagDemon`); единственный Демон превращён — `checkWin`.
  - **Цирюльник**: Демон (не другой Демон, можно себя) меняет двух игроков, стороны прежние; ночь перестраивается.
  - **Заклинатель**: способностью пользовался Философ/Каннибал — прежний Демон становится Философом/Каннибалом (вики),
    новый Демон просыпается Демоном (раньше `gained` оставался и он просыпался Заклинателем — исправлено).
  - **Фань Гу**: прыжок только если Изгой правда умер бы (под защитой Монаха/Трактирщика/Травницы — нет; вики).
  - **Философ**: пьянство выбранного игрока — пока Философ жив, трезв и здоров (`philosopherWorks` в `tokOff`).
  - **Блудница**: Демон умер ночью — ночь перестраивается, новый Демон ходит, если его очередь не прошла. **Чёрт** → Приспешник — `changeRole`.
  - **Каннибал** — по вики уже верно (казнён и умер; злой — отравлен до казни доброго; каждая казнь заменяет способность).
  - **Девица и Егерь** (сделаны 2026-10-11): шаг Девицы — Приспешникам жетон Девицы (в 1-ю ночь; появилась позже — в ближайшую,
    `S.flags.damselShown`); Егерь — раз за игру, отказ сохраняет способность, Девица → Горожанин не из игры (выбирает рассказчик),
    не Девица — ничего; днём карточка «Девица: Приспешник угадывает» (`damselGuess`): одна догадка на всех Приспешников,
    Демон не считается, угадал живую Девицу с работающей способностью — победа зла; жетон `guessused` на Девице.
- **Голосование** идёт по кругу от соседа номинированного, номинированный — последним (`voteOrder` в ui.js).
- **Прачка, Библиотекарь, Сыщик — список ролей** (заметка пользователя 2026-10-12): только то, что можно показать — роли этого типа
  в игре (не своя); есть Шпион/Затворник, способные определиться этим типом, — остальные роли типа отдельной группой; пьян/отравлен/
  Вортокс — «Нет в игре — ложная информация» (`groups` у поля ROLE, `roleGroupOptions` в ui.js). Роль и игроки связаны (`bind` у полей,
  только для верной информации): выбрали роль — её обладатель встаёт в пару; выбрали игроков — роль берётся у игрока этого типа.
  Гробовщик и Смотритель воронов — так же (`shownRoleGroups`: настоящая роль / чем может определиться Шпион или Затворник / ложная);
  трезвому Аэронавту нельзя выбрать игрока того же типа, что прошлой ночью. На экране показа — «Эта роль — один из этих игроков:»
  **над именами** (поле жетона `lead`; формулировка пользователя), имена — по местам (порядок не выдаёт верного).
- **Правка ночного выбора через журнал** (заметки пользователя 2026-10-12: игрок не понял, рассказчик пропустил шаг или ошибся;
  «изменения выдавай отдельным уведомлением и 2 кнопки принять или отмена»). Записи шагов последней ночи в журнале — с ✎; нажатие —
  форма шага в том состоянии, в каком он был, → «Что изменится →» → уведомление: заметки (новые/исчезнувшие шаги, игрок теперь пьян или
  трезв), изменения игроков (жив/умирает, жетоны, роли, сторона), что уйдёт из журнала и что появится → «Принять» / «Отмена». Есть
  «Сделать шаг пропущенным»; «Пропустить» на шаге пишет в журнал «Пропущен шаг: …» — его можно выполнить задним числом.
  Устройство (engine.js): `startNight` → `rpStart` (снимок `S.rp.base`), `applyStep`/`skipStep` пишут записи `S.rp.recs`, интерфейс в `act()`

## Сборка
**Окружение — одной командой, системным Python:** `python tools\setup_env.py`.
Всё тяжёлое лежит ВНЕ проекта (папка проекта в OneDrive — синхронизировать тысячи файлов незачем):
`%LOCALAPPDATA%\botc-grimoire\` → `venv\` (pillow, numpy, scipy, pymupdf), `node\` (Node.js 24.21.0), `git\` (MinGit),
`desktop\` (рабочая папка Electron + node_modules), `electron_cache\`. Скрипт качает только недостающее и сверяет контрольные суммы.
Внимание: приложение Claude изолирует AppData — эти папки видны сессиям Claude, но не обычному терминалу пользователя.

Ниже `PY` = `%LOCALAPPDATA%\botc-grimoire\venv\Scripts\python.exe`:
```
PY tools\app_build_data.py   # data.js из app/data/*.json (без зависимостей)
PY tools\fetch_icons.py      # иконки (качает только недостающие; нужен Pillow)
PY tools\prep_art.py         # вырезка фона арта → art/cut (Pillow, numpy, scipy)
PY tools\app_build.py        # app/dist/grimoire.html + preview.html (Pillow)
python tools\run_tests.py    # тесты движка в headless Edge (без зависимостей)
PY tools\build_sheets.py ; PY tools\render.py   # листы → out/*.pdf (Pillow, pymupdf)
PY tools\site_build.py       # PWA для GitHub Pages → out/site; затем скопировать в docs/
PY tools\desktop_build.py    # Electron: Windows + Mac → out/desktop
python tools\export_files.py # готовое из out/ → Загрузки\Гримуар (без зависимостей)
```
- Mac-сборки собираются из официальных zip Electron в Python (сохраняет симлинки); без подписи — на Mac нужно
  `xattr -cr` и `codesign --force --deep --sign -`.
- Git: `%LOCALAPPDATA%\botc-grimoire\git\cmd\git.exe` (MinGit падает «Filename too long» на очень длинных путях).
  GitHub CLI установлен: `C:\Program Files\GitHub CLI\gh.exe`.

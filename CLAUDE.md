# Гримуар рассказчика и сценарий «Everyone Can Be Evil»

Проект Алекса (Alex) по Blood on the Clocktower («Кровь на часовой башне»). Общаться по-русски.
Перенесён из сессии 2026-10-04/05 (временная папка той сессии удалена — всё нужное здесь).

## Главные правила работы
- **Не выдумывать правила.** Источник: wiki.bloodontheclocktower.com (страница роли → How to Run, Glossary).
  API: `https://wiki.bloodontheclocktower.com/api.php?action=parse&page=<Роль>&prop=wikitext&format=json`.
  Если на вики нет — сказать «решение рассказчика» или спросить пользователя.
- У пользователя **только базовая коробка**: роли Trouble Brewing, Bad Moon Rising, Sects & Violets (+ их Странники и Сказочники).
  Исключение по просьбе пользователя — сценарий **Catfishing 11.1** (Emily): в нём 4 роли из Carousel, жетонов у пользователя нет —
  Аэронавт (Balloonist), Амнезиак (Amnesiac), Каннибал (Cannibal), Вдова (Widow). Они в `EXTRA` в `tools/app_build_data.py`.
- Русские названия — из официального `app/data/ru.json` (botc-translations). Совпадают с жетонами пользователя:
  **Цирюльник** (Barber), **Фань Гу** (Fang Gu), Травница (Tea Lady), Кукловод (Mastermind), Растяпа (Klutz).
- Перед публикацией чего-либо наружу (GitHub, пуш, новые загрузки) — спросить пользователя.

## Уточнённые правила (решения пользователя и проверки по вики)
- **Изгнание Странника:** голосуют все игроки (живые и мёртвые), голос призрака НЕ тратится;
  изгнан, если голосов ≥ половины ВСЕХ игроков с округлением вверх (`exileThreshold` в engine.js). Изгнание — не казнь.
- **Странники** не считаются для «двое живых — победа зла», Блудницы (5+), Мэра; в пороге казни считаются (голосуют).
  Сторону Странника назначает рассказчик.
- **Дурманщик (Poppy Grower)** — по вики МОЖЕТ быть пьян/отравлен: если пьян/отравлен в момент смерти — злые не знакомятся;
  если стал пьян/отравлен — злые «внезапно» не узнают друг друга; если Пьяница считает себя Дурманщиком — знакомство как обычно.
  В движке это свойство роли `prevents_evil_meeting` (data), а не проверка по id.
- **Роли Catfishing в движке** (по вики): яд Вдовы действует, пока Вдова жива и трезва; Аэронавт помнит тип показанного
  прошлой ночью (Затворник/Шпион — тип решает рассказчик), +0/+1 Изгой в раскладке; способность Амнезиака — текст от рассказчика,
  днём догадка «Холодно/Тепло/Горячо/В точку»; Каннибал получает роль казнённого и умершего доброго (`gained`), способность
  «только в 1-ю ночь» срабатывает в ночь после казни (шаг `fresh`), съев злого — отравлен, шаг «понарошку» (`fakeCannibal`).
- **Слова для утра** (`app/src/morning.js`): тон мрачно-торжественный (выбор пользователя); имена в именительном падеже и без
  согласования по роду (пол игроков неизвестен); тексты не раскрывают роли и причину смерти.
- **Куртизанка:** по вики умирают оба; по решению пользователя можно выбрать и смерть одного («Только Куртизанка» / «Только выбранный»).
- **Азартный игрок** не узнаёт, угадал ли: подсказка шага помечена `secret` («Только для вас — не показывайте»); не угадал — умирает,
  пьяный/отравленный — нет.
- Шрифт **Alegreya SC нельзя для кириллицы**: строчная «у» в капители выглядит как латинская Y. Подписи — заглавными с разрядкой.

## Сценарий «Everyone Can Be Evil» (by Alex)
25 ролей, 13/4/4/4, джинксов нет. Список — `four_demons_script.json`.
- Горожане: Библиотекарь, Часовщик, Бабушка, Гадалка, Травница, Монах, Гробовщик, Азартный Игрок, Художник, Придворный, Швея, Мэр, Шут
- Изгои: Цирюльник, Затворник, Дитя Луны, Растяпа
- Приспешники: Злой Близнец, Адвокат Дьявола, Ведьма, Крёстный Отец
- Демоны: Чёрт, Пукка, Но Даши, Фань Гу

## Печатные листы (`tools/build_sheets.py` → `out/roles.pdf`, `out/night.pdf`; копии в `sheets/`)
- Лист ролей: ВСЕ 25 ролей на одной A4. Концепция «Витраж»: тонкая витражная рамка от края листа (внутренний край 7.5 мм),
  сверху дневная, с «Приспешников» плавно переходит в злую (граница вычисляется скриптом в листе). Описания полужирные ~9.8 pt.
  Шапка: название слева, витраж справа. Иконки ролей вшиты (синие у добрых, красные у злых).
- Лист ночей «Двуликий»: слева первая ночь, справа последующие (перевёрнуты на 180°), по центру окно-ланцет.
- Печать: A4, поля «Нет», масштаб 100%.

## Приложение «Гримуар рассказчика» (`app/`)
- Опубликовано как закрытый артефакт claude.ai: https://claude.ai/artifact/Y13UR68ar1MGUMRmiZfk5N (версия 10;
  возможности db+user — игра сохраняется в аккаунте). Обновлять: публиковать `app/dist/grimoire.html` на тот же URL.
- Исходники: `app/src/data.js` (генерируется), `icons.js` (генерируется), `engine.js` (правила, без DOM), `morning.js`
  (слова для утра), `ui.js`, `style.css`. Сценарии: Everyone Can Be Evil, Catfishing, TB, BMR, S&V + загрузка своего JSON.
- Возможности: подготовка (сценарий, круг, раздача с цветом добрых/злых, блефы), пошаговая ночь в официальном порядке
  с «Рамками выбора» (кто выбирает / что решает рассказчик), готовые ответы, учёт яда/защиты/смертей, день (номинации,
  голоса, изгнание), Странники и Сказочники, журнал, отмена через историю снимков (кнопка ↶ + плашка), автосохранение
  всего (включая черновики выбора и незавершённую номинацию), OLED-ночь (#000), крупные строки игроков,
  слова для утра на шаге «Рассвет» (первое утро / без смертей / 1 / 2 / 3+, «другой вариант»), Странники сценария — первыми в списке.
- Интерфейс (решения пользователя, 2026-10-07): днём и на остальных экранах всегда светлая тема (`data-theme="light"`), ночью — OLED;
  плашка отмены — сверху, компактная, 3 секунды. Номинация: свёрнутые «Кто номинирует» / «Кого номинируют» раскрываются
  квадратиками с именами (`tiles`, `pickRow`); голосование и изгнание — тоже квадратиками; внизу зелёная «Подтвердить» и красная
  «Отменить»; одно нажатие выбирает, второе снимает. Изгнание Странника — в самом низу экрана дня.
- **Справочник ролей** — вкладка «Роли» (после «Журнала»): поиск, «этот сценарий / все роли», карточка: официальная способность и
  ночные тексты, тип, издание, раскладка, жетоны, кто в игре, джинксы + «Как вести / Важно / Советы рассказчику» из
  `app/data/guide/*.json` — пересказ вики своими словами (форумы не использовались: их советы нельзя проверить по правилам).
  `app_build_data.py` падает, если у какой-то роли нет справки.
- Раскладка: сдвиг Изгоев с выбором (Крёстный Отец −1/+1 — выбрать обязательно, Аэронавт 0/+1, Сказочник Привратник −1/0/+1)
  рассказчик задаёт кнопками в карточке «Роли» (`S.flags.mods`, `OUT_CHOICES` в engine.js); таблица показывает точные числа
  Горожан и Изгоев (решение пользователя: без «или»). Невозможные варианты не предлагаются (Изгоев < 0 или больше, чем в сценарии);
  Вигормортис при 0 Изгоях ничего не меняет. Случайная раздача следует выбору; Крёстному Отцу без выбора — случайно.
- **Смерти и Странники (проверка 2026-10-06, по вики):** «Убить» (на «Столе» у игрока и карточка «Убить игрока» на экранах
  дня и ночи) — настоящая смерть с причиной-примечанием (`storytellerKill(S, pid, src, reason)`: ночью попадает в рассвет,
  срабатывают последствия; причина — в журнале и на «Столе», `p.deathNote`). Реализованы: Механик (ночь и день), Наёмник
  (`goonHit` в `applyStep`: только шаги с «Игрок выбирает»), мёртвые с `hasability` просыпаются (Вигормортис, Собиратель Костей);
  Странники — Куртизанка, Стрелок, Козёл Отпущения, Судья, Мясник (вторая казнь за день), Бюрократ/Вор (вес голоса
  `voteWeight`), Шаман Вуду (порог 1, голосуют мёртвые без траты жетона), Епископ (номинирует рассказчик, `by='st'`),
  Ученик (`gained` + шаг после заката), Собиратель Костей, Бариста (трезв/дважды), Девиант, Надзирательница, Нищий (трезв;
  жетоны голоса — только подсказка); Сказочники — Кукольник, Фаталист, Скрипач, Герцогиня, «Что-то плохое» (Ангел, Злой
  Библиотекарь) — жетоном. Без механики (решение рассказчика): Революционер, Обманщик, Дух Слоновой Кости, Джинн, Буддист.
- Тесты движка: `app/test/tests.js`, запуск `python tools/run_tests.py` (headless Edge). Сейчас 114/114 (в т. ч. 300 случайных раздач).

## Сборка
**Окружение — одной командой, системным Python:** `python tools\setup_env.py`.
Всё тяжёлое лежит ВНЕ проекта (папка проекта в OneDrive — синхронизировать тысячи файлов незачем):
`%LOCALAPPDATA%\botc-grimoire\` → `venv\` (pillow, numpy, scipy, pymupdf), `node\` (Node.js 24.21.0), `git\` (MinGit),
`desktop\` (рабочая папка Electron + node_modules), `electron_cache\`. Скрипт качает только недостающее и сверяет контрольные суммы.
Внимание: приложение Claude изолирует AppData — эти папки видны сессиям Claude, но не обычному терминалу пользователя.

Ниже `PY` = `%LOCALAPPDATA%\botc-grimoire\venv\Scripts\python.exe`:
```
PY tools\app_build_data.py   # data.js из app/data/*.json (без зависимостей)
PY tools\fetch_icons.py      # иконки (качает только недостающие; нужен Pillow)
PY tools\prep_art.py         # вырезка фона арта → art/cut (Pillow, numpy, scipy)
PY tools\app_build.py        # app/dist/grimoire.html + preview.html (Pillow)
python tools\run_tests.py    # тесты движка в headless Edge (без зависимостей)
PY tools\build_sheets.py ; PY tools\render.py   # листы → out/*.pdf (Pillow, pymupdf)
PY tools\site_build.py       # PWA для GitHub Pages → out/site; затем скопировать в docs/
PY tools\desktop_build.py    # Electron: Windows + Mac → out/desktop
python tools\export_files.py # готовое из out/ → Загрузки\Гримуар (без зависимостей)
```
- Mac-сборки собираются из официальных zip Electron в Python (сохраняет симлинки); без подписи — на Mac нужно
  `xattr -cr` и `codesign --force --deep --sign -`.
- Git: `%LOCALAPPDATA%\botc-grimoire\git\cmd\git.exe` (MinGit падает «Filename too long» на очень длинных путях).
  GitHub CLI установлен: `C:\Program Files\GitHub CLI\gh.exe`.

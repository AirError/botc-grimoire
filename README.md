# Гримуар рассказчика

Неофициальный помощник рассказчика для очной игры в Blood on the Clocktower («Кровь на часовой башне»):
ночной порядок по шагам, подсказки ответов, учёт смертей, голосов и изгнаний, журнал и отмена действий.
Работает в браузере телефона и планшета; в Safari можно добавить на экран «Домой».

Плюс сценарий «Everyone Can Be Evil» (by Alex) и печатные листы к нему.
